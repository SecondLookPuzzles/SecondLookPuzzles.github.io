How to Solve Sudoku: Rules and Tips for Beginners

Updated 1 November 2026

Sudoku is a logic puzzle played on a 9×9 grid divided into nine 3×3 boxes. Your goal is to fill every empty square with a digit from 1 to 9, so that each row, each column and each box contains every digit exactly once. You never need to guess: every square can be worked out from the digits you are given.

In short. Three habits solve almost every beginner Sudoku: fill in the last missing digit of a row, column or box; scan across rows and columns to find where a digit must go inside a box; and check which single digit still fits a square.

What is Sudoku?

Sudoku became a worldwide favourite in the 2000s, and its name is Japanese, short for a phrase meaning "the digits must be single". Each puzzle starts with some digits already in place. Those are fixed, and your job is to fill in the rest.

Although Sudoku uses digits, there is no arithmetic at all. You never add or multiply anything. The digits could just as well be nine different symbols.

Sudoku rules

  1. Every square contains one digit from 1 to 9.
  2. Each row contains every digit once.
  3. Each column contains every digit once.
  4. Each 3×3 box (marked with thicker lines) contains every digit once.

To keep the pictures simple, this guide first uses a mini 4×4 Sudoku with digits 1 to 4 and 2×2 boxes. The rules and techniques are exactly the same.

Three Sudoku solving techniques

1. Find the last missing digit

If a row, column or box has only one empty square left, the missing digit goes there. It sounds obvious, but it is the quickest win in every puzzle.

2. Scan rows and columns into a box

Pick a digit and a box that still needs it. Every row and column that already contains that digit rules out its squares in the box. Often only one square is left.

3. Check which digit still fits a square

Look at one empty square and list the digits already in its row, its column and its box. If only one digit is missing from that list, it goes in the square.

Worked example: solving a mini Sudoku step by step

Follow along with a pencil. Digits shown in orange are the ones we have just filled in. Rows are numbered 1 to 4 from the top, and columns 1 to 4 from the left.

  1. Here is the puzzle: a 4×4 grid with digits 1 to 4. Every row, column and 2×2 box needs each digit once.

  2. Check which digit fits. Row 1 still needs 2 and 3. Column 2 already has a 3, so row 1, column 2 must be 2.

  3. Last missing digit. Row 1 now has 1, 2 and 4, so its last square is 3.

  4. Row 2. It needs 2 and 3. Column 1 already has a 2, so row 2, column 1 is 3, and the other square is 2.

  5. Row 3. It needs 1 and 4. Column 2 already has a 4, so row 3, column 2 is 1, and the other square is 4.

  6. Finish. Row 4 needs 1 and 4. Column 1 already has a 1, so row 4, column 1 is 4, and the last square is 1. Every row, column and box now holds 1 to 4 once.

Common Sudoku mistakes

  • Forgetting the boxes. It's easy to check rows and columns and miss a repeat inside a 3×3 box.
  • Writing in pen too early. Use a pencil, and only write a digit when you are sure.
  • Guessing. A guess can look fine for twenty moves and then fall apart. In a well-made puzzle there is always a logical next step.
  • Staring at one spot. If you're stuck, pick a digit and scan the whole grid for it, box by box.

Sudoku questions and answers

Do I need to be good at maths?

No. The digits are just symbols. Sudoku is about logic and checking, never arithmetic.

Is it better to start with small grids?

A mini 4×4 or 6×6 Sudoku is great for learning the rules. Classic 9×9 puzzles start easy too, so you can move up as soon as the techniques feel natural.

What makes a Sudoku hard?

Fewer given digits help a little, but mostly it's which techniques you need. Easy puzzles can be solved with the three in this guide. Harder ones need more advanced tricks, like pencil marks and pairs.

Does every Sudoku have only one solution?

A well-made puzzle does. The puzzles in this guide were checked by computer to confirm there is exactly one solution.
